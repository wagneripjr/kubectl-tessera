plugin do kubectl · Apache‑2.0 · Go

Dê ao seu agente
uma chave que expira.

kubectl‑tessera emite uma credencial efêmera, de escopo reduzido e com TTL para o cluster atual — rodando como você, protegida por uma verificação de autorização prévia, e limpa automaticamente.

tessera — um símbolo romano de acesso concedido, talhado para conceder exatamente a entrada para a qual foi feito, e então gasto. Isto emite o equivalente moderno: um kubeconfig confinado aos verbos e recursos que você pedir, que se dissolve quando seu tempo acaba.

O que esta ferramenta realmente te dá

O token emitido é sempre restrito — quem quer que o use fica confinado ao escopo que você pediu. O que muda é a garantia sobre seu próprio privilégio.

operador não‑admin

Uma fronteira de segurança real.

A prevenção de escalonamento do RBAC do Kubernetes significa que você fisicamente não consegue emitir um token com mais poder do que você já possui — o API server rejeita vincular a uma role cujas regras você não possui. A fronteira é imposta pelo cluster, não apenas por nós.

operador cluster‑admin

Um limitador de acidentes, não uma contenção.

Se você já possui tudo, a prevenção de escalonamento é vazia — a ferramenta não pode te impedir de exceder o escopo. Ainda é uma proteção eficaz de raio de explosão para um agente, mas a barreira real contra operações destrutivas é a política de admissão (ValidatingAdmissionPolicy / Kyverno).

Sendo direto: tessera é primariamente um limitador de acidentes para o agente, e uma fronteira de segurança real apenas para operadores não‑admin. Ela não contém — e não pode conter — um admin malicioso.

Instalar

Quatro formas de obter o plugin

Instalado como kubectl-tessera no seu $PATH, é invocado como kubectl tessera.

A. krew — assim que for aceito no índice central
kubectl krew
$ kubectl krew install tessera   # aguardando aceitação no krew-index
B. go install — sempre disponível
go ≥ 1.24
$ go install github.com/wagneripjr/kubectl-tessera/cmd/kubectl-tessera@latest
C. script de instalação — sem krew, sem Go; verificado por sha256 (cosign quando presente)
linux / macOS — inspecione, depois execute
$ curl -fsSLO https://raw.githubusercontent.com/wagneripjr/kubectl-tessera/master/install.sh
$ less install.sh   # ele emite credenciais do cluster — confira antes de rodar
$ bash install.sh   # → /usr/local/bin (ou ~/.local/bin)
D. manual — baixe, extraia, coloque no PATH
linux / macOS
$ tar -xzf kubectl-tessera_*_linux_amd64.tar.gz
$ sudo install kubectl-tessera /usr/local/bin/
$ kubectl tessera version
Uso

Delimite o escopo. Coloque um prazo. Vá embora.

Padrões falham em segurança: get,list,watch, com namespace, TTL de 15‑minutos. Você amplia o escopo explicitamente — nunca por acidente. Novo por aqui? Rode kubectl tessera sem argumentos para ver a ajuda e exemplos.

o início mais simples — pods somente‑leitura, namespace atual
$ kubectl tessera --resource pods   # shell interativo, get/list/watch, TTL de 15m
leitor efêmero de todo o cluster — todo tipo de recurso
$ export KUBECONFIG="$(kubectl tessera \
    --resource '*' --all-namespaces \
    --ttl 1h --print-kubeconfig)"
aponte um agente para produção, somente‑leitura, por uma hora
$ export KUBECONFIG="$(kubectl tessera \
    --verb get,list,watch \
    --resource pods,deployments,events,replicasets \
    --namespace prod --ttl 1h --print-kubeconfig)"

$ claude   # somente-leitura em produção, expirando automaticamente em 1h
incidente com escrita restrita — amplie os verbos, encurte o TTL, fixe o objeto
$ export KUBECONFIG="$(kubectl tessera \
    --verb get,list,watch,patch,delete \
    --resource pods --namespace prod \
    --resource-name stuck-pod-abc123 --ttl 20m --print-kubeconfig)"
veja antes de emitir — nada é criado
$ kubectl tessera --resource pods --namespace prod --dry-run   # mostra a Role/RoleBinding que seriam criadas
veja o que está ativo — para humanos ou agentes
$ kubectl tessera ls   # session-id, owner, escopo, expires-at — de cada sessão ativa
$ kubectl tessera ls -o json   # forma programável

Usando --print-kubeconfig? Isso deixa os objetos do RBAC para o coletor — confira o que ainda está ativo com kubectl tessera ls, depois garanta que kubectl tessera gc (ou o CronJob dentro do cluster) rode.

Como se mantém seguro

Privilégio mínimo, por construção

01

Gate prévio

Cada regra pedida é verificada com um SelfSubjectAccessReview. Peça mais do que você possui e ele aborta — imprimindo uma tabela de permitido/negado — antes de criar qualquer coisa.

02

Emitido como você

Os objetos do RBAC são criados com suas credenciais, nunca com um contexto privilegiado ou impersonation. É isso que torna a fronteira não‑admin real.

03

Limpeza em três camadas

O token expira sozinho, o shell interativo intercepta sua saída, e tessera gc varre quaisquer órfãos por label. tessera ls mostra o que ainda está ativo. Nada fica para trás.

Referência

Cada flag, de relance

Flags padrão do kubectl (--context, --kubeconfig, …) são herdadas do cli‑runtime e selecionam qual cluster/identidade usar para emitir.

FlagPadrãoSignificado
--verbget,list,watchVerbos a conceder, separados por vírgula.
--resourceobrigatórioRecursos a delimitar, separados por vírgula (ex. pods,deployments), ou '*' para todos os recursos — o gate SSAR prévio torna isso exclusivo para admins, então não pode te dar mais privilégio.
-n, --namespacecontexto atualNamespace a delimitar — um Role + RoleBinding com namespace.
--cluster-scopedfalseDelimita sobre recursos de escopo de cluster (ex. nodes, clusterroles) — emite um ClusterRole + ClusterRoleBinding.
-A, --all-namespacesfalseConcede o escopo em todo namespace, incluindo os futuros.
--ttl15mTempo de vida do token. Valores abaixo do mínimo do cluster são elevados ao piso e TTLs muito longos podem ser reduzidos — tessera avisa no stderr quando ajusta.
--resource-namenenhumRestringe a concessão a instâncias nomeadas do recurso.
--api-groupinferidoGrupo de API do(s) recurso(s) alvo; necessário só para desambiguar.
--execpadrãoEntra em um subshell interativo com o kubeconfig delimitado; limpa o RBAC ao sair.
--print-kubeconfigImprime o caminho do kubeconfig no stdout. Deixa os objetos do RBAC para o gc.
--dry-runMostra o que seria criado, sem criar.
-o jsonSaída legível por máquina.
